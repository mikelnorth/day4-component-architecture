# Day 4 student projects

Plain Vite + React (JavaScript), same shape as `npm create vite@latest`. These are standalone
copies of the main exercises. For live coding with no setup, use `../exercises/` instead. Each
project here runs on its own:

```bash
cd 01-messy-task-app
npm install
npm run dev
```

| Folder | Lesson | What it is |
|---|---|---|
| `01-messy-task-app` | 3 | Exercise 1 starter: one working file that does everything |
| `02-task-app-refactored` | 3–4 | Exercise 1 solution: split up, with the Total bug left in |
| `03-improve-task-app-starter` | 7 | Exercise 3 starter: the course page's code, for review and fixing |
| `04-task-app-solution` | 5, 7, 9 | Exercises 2 and 3 solution, and the rebuild target |
| `05-dashboard-starter` | 8 | Exercise 4 starter: static version with numbered TODOs |
| `06-dashboard-solution` | 8 | Exercise 4 solution |
